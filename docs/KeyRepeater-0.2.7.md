# 按键连点 0.2.7

## 本次范围

仅更新独立模块 `KeyRepeater`，通过热键栏工坊已发布的 v1 IPC 接口单方面接入。工坊源码、DLL、版本及清单条目均保持 2.3.0，不需要补丁或替换工坊。

## 使用方法

1. 从原在线模块条目更新「按键连点」到 0.2.7。
2. 使用工坊接管时，在工坊中关闭「内置连点」，打开「兼容按键连点模块」。
3. 在按键连点设置中启用「技能栏按住连点」，选择 1–30 CPS。
4. 松开再按住已设置的工坊技能栏快捷键即可；无需为连点单独挑选或配置键位。主、副快捷键自动去重，支持“·”键及 Ctrl/Alt/Shift 组合，修饰键必须完全匹配。

工坊接管时，只使用其接口导出的普通栏 1–10 独立键盘绑定和执行接口，不向原生栏发送模拟输入，宠物栏和任务动作也不走原生模拟。工坊的输入保护、格位映射及冲突优先级继续由工坊负责；页面切换等非技能快捷键不参与连点。

工坊内置连点开启、外部兼容关闭或没有可连点绑定时，接口会导出空列表。独立模块自动让出，不会把空列表当作退出接管，也不会恢复原生栏模拟。

未安装工坊或工坊未接管时，继续自动读取游戏原生普通栏 1–10、宠物栏及任务技能的主、副快捷键，保留 0.2.6 的“·”、鼠标中键 M3、侧键 M4/M5 和组合键支持；原生绑定约 1 秒更新。

## 工坊现有接口的鼠标限制

工坊 **2.3.0** 虽然自身内置连点支持鼠标，但已发布的外部 `Repeat` 接口仍拒绝 Windows VK 4/5/6（M3/M4/M5）。因此 0.2.7 在工坊接管期间跳过这些外部鼠标绑定，并在设置中提示限制和跳过数。需要工坊鼠标连点时使用工坊内置连点；退出工坊接管后，独立模块仍支持原生鼠标绑定。

本次不修改工坊协议，也不通过反射、档案读取或模拟输入绕过工坊执行接口。不能把本版理解为已经支持工坊独立鼠标键的外部连点。

## 安全与兼容行为

- 真实按下负责首次触发；独立模块仅按间隔向 `Repeat(chord, false)` 发送后续连点，完整保留组合键编码。
- 切换原生/工坊来源、重新绑定、切换内外连点或调整模块设置后，仍按住的键必须松开再按。无后台定时器，不补发卡顿期间积压输入。
- 聊天或插件文字输入、未登录、游戏失焦、界面不可用时暂停；工坊继续负责编辑、拖动、职业切换等内部保护。
- 接口注册不完整时暂停；IPC 读取异常、返回空引用或拒绝/异常执行时锁定暂停，且不回退原生输入。处理原因后点击「重新读取技能栏绑定」可重试。
- 工坊正常卸载或退出接管后恢复原生来源，仍需要松开再按。异常锁定时需先手动重新读取绑定。
- 保留 API 1 的 `Settings/config`、`Enabled` 和 `Cps` 配置身份，默认停用、10 CPS。最低宿主沿用 1.1.8.5；与工坊搭配时还需满足工坊自身最低宿主 1.1.8.9。

## 接口依据

使用同仓库已发布协议源码 `Modules/SuperHotbarRepeatProtocol.cs`，只传递框架类型，不引用或加载工坊程序集：

| 端点 | 类型 | 用途 |
| --- | --- | --- |
| `OmniToolbox.Yuzi.SuperHotbar.v1.Active` | `Func<bool>` | 判断工坊是否正在接管 |
| `OmniToolbox.Yuzi.SuperHotbar.v1.Bindings` | `Func<int[]>` | 获取允许外部连点的独立主、副快捷键 |
| `OmniToolbox.Yuzi.SuperHotbar.v1.Repeat` | `Func<int, bool, bool>` | 执行后续连点，首击标志固定为 false |

## 本地交付与游戏内核验

版本化本地文件：`按键连点_KeyRepeater_0.2.7.dll`。本地加载时先停用同身份的旧版或在线版，避免重复加载；历史 DLL 保留。

建议在安全场景检查工坊“·”、Ctrl+“·”主副绑定；确认只发生一个真实首击，后续按设定 CPS 连点，松开即停。再分别切换内置连点、外部兼容、接管开关和聊天输入，确认暂停及松开重按行为。工坊鼠标键使用其内置连点验证，独立模块的原生 M3/M4/M5 在退出接管后验证。
