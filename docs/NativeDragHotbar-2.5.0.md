# 热键栏工坊 2.5.0

接替游戏原生热键栏，支持自由布局、独立快捷键、职业切换与扩展栏，提供多套配置、连点、备份和还原。

正式版汇总 2.4.0 之后的更新，沿用内部身份 NativeDragHotbar、原库链地址及 Modules/NativeDragHotbar.dll 路径。最低 Omni 1.1.8.9；模块和产品版本 2.5.0，程序集和文件版本 2.5.0.0。

## 更新与使用

- 接管栏独立保存位置、排列、缩放，不持续吸附原生栏。同一 Omni 配置目录中的角色和账号使用同一套配置即可沿用。旧跟随字段被忽略，已有坐标沿用；旧版已经覆盖的位置需自行重新摆放。
- 显隐命令先将小记录刷新到磁盘，成功后生效，连续命令结束约 0.75 秒后合并完整配置。减少反复重写大型档案；已成功执行的显隐命令可在即刻退出后恢复。其他编辑继续自动保存，保存失败时请重试。
- 隐藏原生栏时同步暂停其鼠标检测，退出接管、HUD 编辑、特殊栏及切角色时释放。避免空白位置仍响应原生技能。
- 接管栏图标、冷却、键位及锁绘制在插件窗口下方；真实窗口和控件优先接收操作，透明载体的空白不误挡栏位。缩小输入范围，修正鼠标刚移入或重载后的首次点击丢失，每次加载创建独立鼠标窗口。
- 过场、切图和游戏隐藏 HUD 时，两种栏临时隐藏并暂停快捷键、连点、拖放和悬停提示。恢复后沿用原显示设置，不保存临时隐藏。
- 重新读取全部栏位布局需二次确认，只读取一次并覆盖当前配置的布局、缩放和显示状态，保留内容、快捷键；取消不改动配置。它不是使用已保存位置的必要步骤。
- 移除测试与排查面板、点击采集、排查记录和手动重建工具。本地 2.4.8 保留供需要时排查；正式版保留输入窗口生命周期修正。

## 跨角色游戏设置模板

在「备份与导入」选定当前配置，展开「跨角色游戏设置模板」。

1. 来源角色先保存并关闭游戏「界面设置」。进入「读取／更新模板」，选择范围，点击「读取游戏设置模板…」，预览后确认保存。
2. 换角色后点击「应用到当前角色…」，核对差异后确认。应用前保存当前角色备份，完成后读回核对并请求游戏保存。
3. 可开启「其他角色首次使用这套配置时自动应用模板」。界面就绪、非战斗且非过场时等约 3 秒应用一次；来源角色不会自动重套。对同一模板只自动应用一次，之后手动修改保留；重新保存模板后可自动应用新版。
4. 自动应用过后仍可再次手动应用。「恢复应用前设置…」读取当前角色最近的应用前备份，预览确认后恢复。
5. 数量、补充说明和删除入口在「模板详情与管理」。读取、应用、恢复、删除时只显示当前确认内容；取消清除旧预览。

范围包括：其他 HUD 与窗口布局、角色操作与显示、其他快捷键，以及默认不选的系统画面与声音。接管栏自身位置由当前配置保存，用户宏使用单独备份和还原入口。系统设置影响客户端，不复制分辨率、显示模式、设备选择、登录信息或游戏进度。

模板读取使用游戏认可的有效条目，跳过失效缓存，兼容客户端默认值和无需改变的当前值；结构、类型、重复条目和数值仍检查。应用失败会按已验证的应用前备份尝试恢复，游戏写回不是事务操作，需核对结果。客户端结构变化时需重新读取模板。

## 配置、宏与备份

现有 2.4.0 配置继续读取，无需删除重建。配置保存到 Omni 配置目录的 HotbarWorkshopProfiles.json，并保留 .bak；显隐记录位于 HotbarWorkshopVisibility，模板应用前备份位于 HotbarWorkshopGameSettingsBackups。

- 本机其他角色沿用最后选中的配置，可自行新建、复制、重命名和删除多套配置。独立配置目录或其他电脑需导出、导入。
- 完整配置导出包含接管栏、扩展栏、已保存的宏备份和游戏设置模板。仅接管档案或扩展栏导出不包含游戏设置模板；导入或复制后模板自动应用默认关闭，已应用角色记录不随分享传播。
- 接管栏与扩展栏执行当前角色「用户宏」中的实时内容；编辑后直接生效。「更新用户宏备份…」只更新备份。跨角色执行同分类、同编号的当前宏，不会自动覆盖宏正文。
- 左键使用、右键编辑；Alt＋左键移动整栏。接管栏编辑和移动需解锁，扩展栏不受接管锁影响。
- 「还原到游戏」经预览确认后才将所选热键栏、键位或宏写入当前角色，先备份并请求游戏保存；「退出接管，使用游戏热键栏」只停止接管，保留模块配置。

## 安装

在 Omni 在线模块刷新原库链并更新热键栏工坊。使用本地 DLL 的用户先停用旧条目，再启用在线版，避免同名模块重复加载。原库链：

https://raw.githubusercontent.com/yuanzil1243-oss/OmniToolbox.yuzi/main/TreeHouseModules.json

本次重新构建正式 DLL，并核对模块、程序集、文件和清单版本及 SHA256。发布完成后从原库链重新下载清单和 DLL 核验；发布记录与测试日志保存在项目 work/release-2.5.0。

间歇性 8、10 栏问题在用户游戏中已恢复，但原触发条件尚未确认。本版保留已验证的鼠标修正，不将一次恢复视为全部现场原因已经定位。
