热键栏工坊 2.5.0

本次更新主要完善跨角色使用体验。接管栏独立保存位置，换角色后直接沿用；新增游戏设置模板，可以一并带上其他界面布局和常用设置，同时优化保存、显示和鼠标操作。

本次主要更新：

- 接管栏独立保存位置
  位置、横竖排列和缩放保存在当前配置中，不再跟随游戏原生栏移动。同一电脑、同一 Omni 配置目录下，其他角色或账号选用同一套配置即可直接使用。
- 跨角色游戏设置模板
  在「备份与导入」保存其他界面与窗口布局、角色操作与显示、其他快捷键，也可选保存系统画面与声音。支持手动应用，或在其他角色首次使用这套配置时自动应用；应用前会备份当前角色的设置。
- 显隐命令保存优化
  显示、隐藏栏位时先保存一份小记录，再合并到完整配置，减少连续指令反复保存大档案造成的停顿。已成功执行的显隐命令，即使随后使用即刻退出，下次载入也能恢复最近状态。
- 完善接管时的鼠标处理
  隐藏原生栏时同步暂停其鼠标检测，避免空白位置仍弹出旧技能提示。改进透明窗口误挡、相邻栏边缘抢鼠标，以及重载后首次点击丢失的问题。
- 调整显示层级与过场隐藏
  接管栏显示在其他插件窗口下方，覆盖它的正常窗口优先接收操作。过场、切图或游戏隐藏 HUD 时，两种栏会一起临时隐藏，结束后恢复原来的显示状态。
- 整理模板操作与布局读取
  简化模板页面和确认步骤，修正部分默认值、窗口缓存导致的预检问题，自动应用后仍可再次手动应用。「重新读取全部栏位布局…」增加二次确认，避免误覆盖已保存的位置。

原库链地址不变，刷新在线模块并更新「热键栏工坊」即可。现有配置继续使用，无需删除或重新读取；本次正式版已移除测试与排查工具。

使用方法：

1. 保存共用的接管栏布局
   在「备份与导入」选好「当前配置」，解锁接管栏后用 Alt＋左键移动，在「栏位与布局」调整排列和缩放，等待自动保存。之后换角色或账号，使用同一套配置即可，无需重新读取游戏布局。
2. 保存游戏设置模板
   在设置好的角色上保存并关闭游戏「界面设置」，打开「备份与导入」→「跨角色游戏设置模板」→「读取／更新模板」，选择范围，点击「读取游戏设置模板…」并确认保存。
3. 应用到其他角色
   换角色后选择同一套配置，点击「应用到当前角色…」，核对后确认。也可勾选「其他角色首次使用这套配置时自动应用模板」；每个角色对同一份模板只自动应用一次，之后的手动调整会保留。
4. 恢复应用前设置
   如需撤回模板应用，点击「恢复应用前设置…」，预览并确认。备份只用于原来的角色；需要重套模板时，可以再次手动应用。
5. 备份配置与用户宏
   使用「导出配置…」选择完整配置，可一并保存接管栏、扩展栏、已备份的宏和游戏设置模板。日常编辑宏直接在游戏「用户宏」中进行；需要更新保存的宏备份时，再点「更新用户宏备份…」。
6. 将配置写回游戏
   需要把保存的热键栏、键位或宏写入当前角色时，使用「还原到游戏」预览并确认，模块会先备份再写入并请求游戏保存，可作简单的本地配置备份恢复。仅停止接管时，点击「退出接管，使用游戏热键栏」即可。

接管栏自身的位置直接由当前配置保存，游戏设置模板负责其他界面和设置。模板不会自动覆盖用户宏；系统画面与声音默认不选，不复制分辨率或设备选择。使用本地测试版的用户，请先停用旧本地条目，再启用在线版，避免重复加载。
