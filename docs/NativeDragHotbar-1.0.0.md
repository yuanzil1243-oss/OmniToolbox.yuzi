# 拖放热键栏 1.0.0

作者：Yuzi。Omni 模块 NativeDragHotbar，模块版本 1.0.0，实际程序集和文件版本 1.0.0.0。依赖 Omni 1.1.8.9、Dalamud Hooks dev；模块 API 1，.NET 10 / Windows x64。

## 自由布局与格子编号

布局由固定下拉选项改成“横向 [数字] × 纵向 [数字]”。填写正整数后点击“应用布局”，总格数等于两数相乘，每栏最多 120 格，最多 12 条热键栏。例如 7×3 为 21 格，10×4 为 40 格，1×1 为 1 格。

扩大布局时追加空格；缩小时只隐藏多出的格子，内容按原有顺序保存在角色配置中。设置区会显示隐藏格和其中已配置格子的数量。以后扩大容量即可恢复，重新登录和导入导出也保留隐藏内容。只有删除整条热键栏才会同时删除其隐藏格。

悬浮热键栏不再显示格内数字；模块设置中的格子按钮仍保留编号，按窗口宽度换行，点击编号可编辑对应格子。

旧版 12 格配置自动迁移，原有排列、动作、附加指令、显示选项、缩放、不透明度和位置锚点保留。首次保存迁移后配置时原文件进入 .bak。新配置为 schema 2，旧模块不识别该格式，更新后请使用新版并保留备份。

“隐藏空格”沿用原行为：空格不显示，其余内容紧凑排列；拖入时自动展开。如果要保持完整矩形及中间留空，请关闭“隐藏空格”。格子很多时可结合缩放选择适合屏幕的排列。

## 导入导出

模块设置中新增三个按钮：

- “导出当前栏”：把选中栏的完整设置复制到剪贴板，包括布局、全部显示格和暂存隐藏格、原生动作、图标、名称、说明、附加指令、显示状态、缩放、不透明度及位置。
- “导出全部设置”：导出全部栏，并包含“显示全部热键栏”和“显示操作说明”两个全局选项。
- “从剪贴板导入…”：复制之前导出的完整文本，点击此按钮查看预览，再点“确认追加导入”。可点取消放弃。

导出后可将剪贴板内容粘贴到文本文件自行保存。导入只接受本模块的 NativeDragHotbar.Settings 格式，不是其他热键栏插件的导出格式。

导入会追加成新栏，不覆盖已有栏；会生成新内部身份，同名栏会加“(导入2)”等后缀。默认保留当前的两个全局选项；导入全部设置时可勾选“同时恢复全局显示和操作说明设置”。超过 12 条上限时不能确认，需先取消并删除不需要的栏。

支持将导出文本用于其他角色，不携带来源角色 ContentId；原生技能、物品、宏和套装等身份仍依照游戏自身定义，使用时取决于目标角色实际拥有的内容。导入不会执行其中的动作或自定义指令。名称有变化时，使用栏名定位的自定义指令需要自行核对。

原生热键栏锁定时不能确认追加导入；请先在游戏内解除锁定。导出不受锁定影响。

在 Omni 本地模块管理中停用旧版，更新为 `拖放热键栏_NativeDragHotbar_1.0.0.dll` 后启用。不要同时启用多个版本，不要删除角色配置。

## 验证与游戏内检查

已为任意行列、120 格上限、缩小再扩大、隐藏格持久化、旧版六种布局迁移、跨角色导入、同名和身份处理、无效导入原子拒绝、全部栏导出及第 120 格内容增加离线回归检查。构建和打包脚本还会验证 Omni API 契约、实际版本和最终 DLL/ZIP 摘要。

本轮未安装或操作游戏，用户自行更新测试。建议验证：7×3 应用后出现 21 格；配置靠后格子再缩到 2×2，重启后扩大确认内容恢复；导出当前栏与全部设置，检查导入预览、取消、确认及编号；检查悬浮栏无数字、模块设置保留数字。

构建与打包：`pwsh -NoProfile -File build/NativeDragHotbar/Package.ps1`。
