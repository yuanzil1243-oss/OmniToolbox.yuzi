作者：Yuzi。模块版本 1.1.0，实际程序集及文件版本 1.1.0.0。最低 Omni 1.1.8.9，模块 API 1，.NET 10 / Windows x64。

## 1.1.0 更新内容

整合此前 1.0.1—1.0.3 本地测试版的改动，发布为正式版 1.1.0。

- 支持在自定义指令编辑框使用 `/micon 惊讶 emote` 等图标指令。图标优先级：指令设置 ＞ 自主选择 ＞ 原生或自动设置；删除指令图标设置后恢复手选图标。
- 有自定义指令且无可用图标的格子，自动从 234001—234063 中随机分配一个图标并保存；重新登录和导入导出不重抽。
- 修复显示切换指令。使用 `/draghotbar toggle`，旧命令 `/draghotbar show` 也可切换；支持 #编号及栏名，`on` 显示、`hide/off` 隐藏，并反馈切换结果。
- 不透明度支持 0—1，仅影响栏背景、格子底色及边框；图标保持清晰，0 不透明度下仍可点击、右键编辑。
- 替换确认窗保持居中并持续置于编辑窗上方；等待确认时编辑窗略微压暗并暂停接收输入，确认、取消或关闭后恢复。
- 移除自定义指令格右下角的 C 标记。

本地 DLL 与在线 DLL 为同一构建。指定本地目录只放 DLL 与使用说明，ZIP、清单及校验记录保存在项目 outputs 目录。在线版与本地版使用相同模块身份和角色配置，请避免同时启用两个副本。

## 保留的界面行为

- 不透明度仅影响热键栏背景、外框、热键格底色与边框；技能、物品、宏图标保持原有清晰度。不透明度为 0 时背景和格框消失，已有图标继续显示并可点击、右键编辑。
- 替换确认窗持续置于编辑窗口上方，并保持在编辑窗口中央。等待确认时编辑窗不接收鼠标、键盘、移动或缩放操作，避免重新抢到前面；确认、取消或关闭确认窗后恢复。
- 确认期间仅在编辑窗口覆盖约 18% 的黑色遮罩，使其略微压暗，不压暗游戏画面或确认窗口。

建议先在 1、0.5、0 三档不透明度下确认图标亮度不变；再拖入替换已有格子，尝试点击编辑窗，检查确认窗仍在前面，取消后编辑窗亮度与输入恢复。

## 已有功能与测试方式

### 指令图标与优先级

在自定义指令编辑框内使用 `/micon 惊讶 emote`，或 `/macroicon "名称" 类型`。名称有空格时加双引号，省略类型时按 action 处理。

图标优先级为：有效的指令图标 ＞ 自主选择的图标 ＞ 原生或自动图标。指令图标仅控制显示，不覆盖保存的手选图标；删除 /micon 后会恢复手选图标。无法解析的名称或类型会继续使用备用图标。编辑窗口的预览与悬浮栏使用相同解析结果，/micon 本身不作为聊天指令发送。

支持按当前游戏数据查找 action（含生产技能）、emote、general、item（含任务道具）、mount、minion/companion、pet；也支持 classjob、gearset、waymark、marking、ornament 对应的名称或适用编号。不是完整的游戏宏执行器，仍不实现 /wait 等宏等待机制。

只有设置了自定义指令、且没有任何可用图标的格子，才会在图标 ID 234001—234063 中随机分配一个图标。保存后保持不变，重新登录、调整布局与导入导出不会重抽。空格子不分配图标。

建议使用以下文本测试：

```text
/micon 惊讶 emote
/surprised motion
/em 发现<t>！
```

先手选其他图标，输入上述文本确认显示“惊讶”；删除 /micon 行后确认恢复手选图标。新建纯指令格、图标 ID 留 0，保存后检查自动图标是否位于指定范围。

### 显示切换指令

设置页示例改为 `/draghotbar toggle`。旧示例 `/draghotbar show` 保留为切换别名，重复输入可以显示、隐藏交替。`on` 明确显示，`hide` 或 `off` 明确隐藏；可追加 #编号、完整栏名，含空格名称可加双引号。切换结果会在聊天中反馈。

```text
/draghotbar toggle
/draghotbar show
/draghotbar toggle #1
/draghotbar toggle "常用功能"
/draghotbar on #1
/draghotbar hide #1
```

未指定栏时切换整体显示；如果所有单栏均隐藏，显示时会恢复全部栏，避免整体开启却没有任何栏出现。指定单栏时，即使整体开关关闭也能将该栏显示出来。

### 替换确认位置

在指令编辑窗口拖入并替换已有动作时，确认窗口固定在当前编辑窗口中央并持续置前；确认期间编辑窗口略微压暗且暂不接收输入。没有编辑窗口时使用游戏视口中央。

### 背景和格子透明度

不透明度范围为 0—1，窗口背景、格子底色与边框同步变化，图标不受该滑块影响。0 表示背景和格框完全透明，已有图标仍然可见并可操作；设置窗口不随之透明。

## 自由布局与格子编号

布局由固定下拉选项改成“横向 [数字] × 纵向 [数字]”。填写正整数后点击“应用布局”，总格数等于两数相乘，每栏最多 120 格，最多 12 条热键栏。例如 7×3 为 21 格，10×4 为 40 格，1×1 为 1 格。

扩大布局时追加空格；缩小时只隐藏多出的格子，内容按原有顺序保存在角色配置中。设置区会显示隐藏格和其中已配置格子的数量。以后扩大容量即可恢复，重新登录和导入导出也保留隐藏内容。只有删除整条热键栏才会同时删除其隐藏格。

悬浮热键栏不再显示格内数字；模块设置中的格子按钮仍保留编号，按窗口宽度换行，点击编号可编辑对应格子。

旧版 12 格配置自动迁移，原有排列、动作、附加指令、显示选项、缩放、不透明度和位置锚点保留。首次保存迁移后配置时原文件进入 .bak。新配置为 schema 2，旧模块不识别该格式，更新后请使用新版并保留备份。

“隐藏空格”沿用原行为：空格不显示，其余内容紧凑排列；拖入时自动展开。如果要保持完整矩形及中间留空，请关闭“隐藏空格”。格子很多时可结合缩放选择适合屏幕的排列。

## 导入导出

模块设置中新增三个按钮：

- “导出当前栏”：把选中栏的完整设置复制到剪贴板，包括布局、全部显示格和暂存隐藏格、原生动作、图标、名称、说明、附加指令、显示状态、缩放、不透明度及位置。
- “导出全部设置”：导出全部栏，并包含“显示全部热键栏”和“显示操作说明”两个全局选项。
- “从剪贴板导入…”：复制之前导出的完整文本，点击此按钮查看预览，再点“确认追加导入”。可点取消放弃。

导出后可将剪贴板内容粘贴到文本文件自行保存。导入只接受本模块的 NativeDragHotbar.Settings 格式，不是其他热键栏插件的导出格式。

导入会追加成新栏，不覆盖已有栏；会生成新内部身份，同名栏会加“(导入2)”等后缀。默认保留当前的两个全局选项；导入全部设置时可勾选“同时恢复全局显示和操作说明设置”。超过 12 条上限时不能确认，需先取消并删除不需要的栏。

支持将导出文本用于其他角色，不携带来源角色 ContentId；原生技能、物品、宏和套装等身份仍依照游戏自身定义，使用时取决于目标角色实际拥有的内容。导入不会执行其中的动作或自定义指令。名称有变化时，使用栏名定位的自定义指令需要自行核对。

原生热键栏锁定时不能确认追加导入；请先在游戏内解除锁定。导出不受锁定影响。
