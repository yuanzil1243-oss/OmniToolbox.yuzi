# 按键连点 0.2.6

## 范围与用法

- 本次只更新独立模块 `KeyRepeater`，不修改热键栏工坊，也不接入其独立快捷键或连点 IPC。
- 自动读取游戏原生普通技能栏 1–10、宠物栏和任务技能的主、副快捷键，按住已绑定键即可按 1–30 CPS 连点，无需逐个配置。
- 新增“·”（波浪号/OEM_3 键）、鼠标中键 M3、侧键 M4/M5 的正确识别和发送；支持 Ctrl/Alt/Shift 的任意组合，左右修饰键同义，必须完全匹配。
- 默认停用；在模块设置中勾选「启用技能栏按住连点」并选择速度。首次输入由真实按下触发，后续按间隔发送，不额外重复首击。
- 松开普通键或任一组成键后停止；聊天/插件文字输入、游戏失焦、未登录或界面不可用时暂停。切回游戏、重新绑定、变更速度/开关后需要松开再按，避免把旧按住状态用于新场景。
- 游戏绑定修改后约 1 秒自动更新；重复绑定只连点一次，不支持的键位单独跳过，不阻断其他可用绑定。无后台定时器，不补发卡帧期间的积压输入。
- 保留 API 1 的 `Settings/config` 和原 `Enabled`、`Cps` 字段；宿主继续保存配置。版本为 0.2.6，实际程序集/文件版本为 0.2.6.0，清单最低宿主沿用 1.1.8.5。
- 使用热键栏工坊接管和内置连点时，关闭本模块；本版不为工坊的独立键位提供连点，不会自动协调两个模块的连点开关。

## 实现依据

- 游戏 `KeySetting.Key` 是游戏键码，不可直接当 Windows VK。运行时通过公开 `IKeyState.TryGetSeVirtualKey` 建立反向表。2026-11-09 只读 MCP 实测 `VK_OEM_3 (192)` 对应游戏码 `136`；回归测试保存此映射及其他标点键映射，不保存实际键盘输入或角色信息。
- 鼠标读取逻辑与工坊现有规则一致：游戏 `PAD_MMB=161`、`PAD_MB4=163`、`PAD_MB5=164` 分别转换为 Windows 4、5、6。支持旧的 4/5/6 别名；不接受普通左右鼠标键、仅修饰键、未绑定或未知键码。
- 键盘沿用 OmenTools 输入封装；鼠标向游戏窗口成对发送 `WM_MBUTTONDOWN/UP` 或 `WM_XBUTTONDOWN/UP`，正确填写 XBUTTON 高位及 Shift/Ctrl/其他鼠标键状态，不注入修饰键抬起，也不向系统全局注入鼠标。

## 升级核验

从原在线条目更新即可；使用本地 DLL 时，先停用在线版或旧本地版，避免同一身份重复加载。历史 DLL 保留，新 DLL 使用带版本文件名。

建议在不影响战斗的场景分别检查“·”、Ctrl+“·”、M4、Ctrl+M5 的持续按住与松开；再确认输入聊天或切换窗口时暂停。热键栏工坊维持原版，不需要为此次更新替换。
