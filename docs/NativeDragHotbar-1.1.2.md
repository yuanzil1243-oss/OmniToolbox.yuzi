# 拖放热键栏 1.1.2 — 本地共享配置正式版

作者：Yuzi。模块版本 1.1.2，程序集与文件版本 1.1.2.0。模块 API 1，最低 Omni 1.1.8.9，.NET 10 / Windows x64。本次使用当前已安装的 Omni 1.1.9.8 和 Dalamud 依赖构建与校验。

本版本正式发布本地共享配置功能，由 1.1.1 本地测试版递增版本并重新构建。功能与本地测试版保持一致。

正式仓库：https://github.com/yuanzil1243-oss/OmniToolbox.yuzi

正式库链：https://raw.githubusercontent.com/yuanzil1243-oss/OmniToolbox.yuzi/main/TreeHouseModules.json

## 本次修改

- 所有账号和角色默认共用同一份本地热键栏设置，不再按角色切换配置，也不提供角色独立模式。
- 热键栏内容、自定义指令、图标、栏名称、布局、显示状态、隐藏格、缩放、不透明度和位置锚点都共用。
- 配置统一保存在 Omni 插件配置目录中的 `NativeDragHotbar-shared.json`，备份为同名文件加 `.bak`。这里的“本地共享”指使用同一 Omni 插件配置目录的账号与角色，不是联网同步，也不会自动跨电脑同步。
- 切换角色时取消未保存的格子编辑草稿、待确认替换和拖动操作，已保存的热键栏保持不变。已经应用到热键栏但暂时写入失败的设置继续保留在内存中，不会因换角色被默认配置替代；设置页提供重试保存。
- 登录角色仍是原生拖入、执行和配置界面的前提；角色身份只用于隔离当前交互，不再决定配置文件。

## 升级说明

从 1.1.1 本地测试版升级时，继续读取相同的共享配置文件，不重复迁移。以下迁移规则适用于 1.1.0 及以前的角色独立配置版本。

先停用旧版，然后在 Omni 本地模块管理中选择 `拖放热键栏_NativeDragHotbar_1.1.2.dll` 并启用；避免同时启用两个版本。建议首次启用时登录已经配置好热键栏的角色。

首次建立共享配置时：

1. 已有共享配置或共享备份时始终优先读取，不再重新迁移旧角色配置。即使共享配置被主动清空，也不会恢复出旧热键栏。
2. 没有共享配置时，优先读取当前角色已有格子内容的旧配置，包括暂存的隐藏格。
3. 当前角色只有空栏或没有旧配置时，选择本地最近保存、且含有格子内容的可读旧角色配置。不会因为新账号产生了空栏，就丢下其他账号已有的设置。
4. 所有可读旧配置都没有格子内容时，保留当前角色的空栏及布局设置；没有当前角色文件则采用最近保存的可读旧配置。没有旧文件才建立默认空栏。
5. 只选择一份旧配置作为起点，不自动合并不同角色的热键栏，避免重复栏和超出 12 栏上限。需要其余旧栏时，可使用旧版本导出的文本追加导入。

原有 `NativeDragHotbar-角色ID.json` 与其 `.bak` 不删除、不改写。迁移支持旧 schema 1、2，并在共享文件中沿用 schema 2；持久化身份标记改为全零的本地共享身份。发现损坏主文件时保留损坏副本，优先使用有效备份。

如果当前角色旧配置及其备份都不可读，或者找不到有内容的可读配置但仍有无法读取的旧配置，暂停迁移并在日志中报错，避免用空配置掩盖原设置。已有共享主文件与备份均损坏、身份不匹配或版本过新时，同样暂停编辑和写入，不静默回退成另一角色的配置。

迁移后的所有修改只写共享文件。降级到 1.1.0 会再次读取当时保留的旧角色文件，不会获得共享文件里的后续修改。回退前请先导出需要保留的设置。

## 操作与保留功能

- 从原生技能页、热键栏、背包等位置拖入；左键执行，右键编辑。原生热键栏锁定时仍能拖入，禁止栏内换位和删除。Alt + 左键移动整栏。
- 自由设置横向 × 纵向，每栏最多 120 格、最多 12 栏。缩小布局只暂存隐藏格，扩大可恢复；浮动栏隐藏格子编号，模块设置中保留编号。
- 原生动作可保留并追加自定义指令；拖到指令编辑文本框可插入技能、功能名称或情感动作指令。
- `/micon 惊讶 emote` 等图标指令优先于手选、原生和自动图标；纯指令且没有可用图标时，从 234001—234063 随机分配一次并保存。移除 /micon 后可恢复手选图标。
- `/draghotbar toggle [#编号或名称]` 切换显示；`show` 同样切换，`on` 显示，`hide/off` 隐藏。
- 不透明度为 0—1，只影响栏背景、格子底色与边框，图标及其点击不受影响。替换确认保持编辑窗口居中置前，等待确认时仅压暗并禁用编辑窗口。
- 导出当前栏、导出全部设置，以及从剪贴板预览并追加导入继续可用，兼容 1.1.0 导出的文本。导入后所有角色都能使用这些栏。导出文本仍不携带角色身份；超过 12 栏不能确认追加导入，确认前需解除原生热键栏锁定。

共享配置不会赋予角色尚未获得的技能、物品、情感动作等；宏与套装仍按当前角色相应编号执行，其实际内容可能不同。切换角色后如有需要，请检查这些格子。仍未实现键盘绑定、原生冷却动画或 `/wait` 等宏等待机制。
