# 热键栏工坊 2.3.0

接替游戏原生热键栏，支持自由布局、独立快捷键、职业切换与扩展栏，提供连点、备份和还原。

作者：Yuzi。发布日期：2026-11-09。模块／产品版本 2.3.0，程序集／文件版本 2.3.0.0。API 1，最低 Omni 1.1.8.9。本轮使用 Omni 1.1.9.8、Dalamud 15.0.3.9 构建并进行离线验证。

## 从拖放热键栏升级

- 本版正式接替“拖放热键栏”1.1.4，沿用原模块条目、内部身份 `NativeDragHotbar` 及文件路径 `Modules/NativeDragHotbar.dll`，不新增第二个热键栏模块。
- 原正式库链地址不变：`https://raw.githubusercontent.com/yuanzil1243-oss/OmniToolbox.yuzi/main/TreeHouseModules.json`。在 Omni 刷新在线模块并更新原来的“拖放热键栏”，更新后显示为“热键栏工坊”。
- 已有扩展栏继续读取 `NativeDragHotbar-shared.json` 与其备份，无需删除或重新导入。更早的按角色扩展栏配置继续按既有规则迁移，旧文件保留。
- 2.x 本地版本的接管档案、布局、快捷键与备份继续兼容。接管档案按角色保存，扩展栏在本机同一 Omni 配置目录下的所有账号与角色间共用。
- 如果以前手动登记过本地 DLL，请先停用或移除旧本地登记，再启用在线版本，避免同一个内部模块重复加载。使用本地 DLL 时也只保留一个启用的版本。
- 本地交付文件为 `热键栏工坊_NativeDragHotbar_2.3.0.dll`；旧版 DLL 与历史说明保留，更新前建议导出完整备份。

## 两种使用方式

### 只用扩展栏

无需启用接管；在“扩展栏”中添加栏位，从游戏拖入技能、道具、宏或功能按钮。左键使用，右键编辑，Alt + 左键移动整栏。扩展栏的移动和编辑不受接管栏及游戏原生栏的锁定影响。

### 接替游戏原生热键栏

首次在“备份与导入”读取游戏配置，检查“栏位与布局”和“快捷键”后启用接管。普通原生热键栏由模块绘制并使用独立快捷键，内容按角色和职业管理；十字热键栏、宠物栏及特殊临时栏不属于普通栏接管范围。

点击“退出接管，使用游戏热键栏”会恢复游戏原生栏，模块档案及扩展栏继续保留。退出接管本身不会把模块档案写回游戏。

## 功能与操作

- 支持自由行列、缩放、背景透明度及显示控制；缩小布局保留超出部分的格子内容。
- 支持原生动作和自定义指令，保留 `/micon`、`/macroicon` 图标设置。识别受支持的技能宏、道具宏等并显示对应技能介绍或物品详情；不会为了识别宏而执行它。
- 扩展栏与设置格子均可右键编辑；接管栏编辑和移动前需解锁。操作说明直接显示，栏位设置卡片在载入和重新启用时默认折叠。
- 命令列表中的命令可以点击复制；指令聊天反馈可通过“显示指令文本提示”开关控制。
- 工坊提供内置连点设置。本次不更新独立“按键连点”模块及其正式版本。
- “复制完整档案到剪贴板”导出接管档案，旁边的组合备份按钮可以把扩展栏配置一并导出；导入前可以预览和选择范围。
- 设置通常自动保存。“立即保存／重试”用于立即写入或重试保存当前角色的本地接管档案，不负责写回游戏，也不作为扩展栏的单独保存按钮。
- 只有“还原到游戏”页面中的明确确认操作会把选定内容写回游戏；执行前先备份游戏当前配置，再写入并读回核对。

## 常用命令

- `/superhotbar toggle [#编号或名称]`：切换扩展栏显示。
- `/superhotbar takeover toggle [#编号或名称]`：切换接管栏显示；隐藏接管栏后，已启用的快捷键仍可使用。
- `/superhotbar native`：退出接管，恢复游戏热键栏。
- 显示控制支持 `on` 显示、`hide/off` 隐藏，`show` 与 `toggle` 一样执行切换。保留 `/draghotbar` 作为兼容入口。
