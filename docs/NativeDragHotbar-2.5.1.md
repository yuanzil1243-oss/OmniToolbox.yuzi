# 热键栏工坊 2.5.1

接替游戏原生热键栏，支持自由布局、独立快捷键、职业切换与扩展栏，提供多套配置、连点、备份和还原。

本次主要更新：

- 旧模板兼容：修正仅因依赖更新就提示“结构不一致”的预检。按键实际结构与指令编号兼容的已验证旧模板可直接使用，无需重新读取。界面条目、选项类型、数值范围和目标按键仍会检查；未验证兼容的模板保留原档案并提示，不自动覆盖。
- 读取与保存分开：当前配置首次建档使用「读取游戏配置…」。已有接管档案时主按钮显示「保存」，保存工坊当前的技能、自定义指令、布局、快捷键和扩展栏。日常修改仍自动保存。
- 收起重新读取：放入「重新读取游戏配置」，预览时须另行勾选覆盖确认。重新读取会替换接管档案，包括工坊编辑的自定义指令，只在确实需要重建时使用。
- 显隐状态单独保存：接管栏和扩展栏的显隐命令、设置页显示开关均写入小型状态文件。取消显隐后延迟合并整份配置的步骤；单纯切换显隐不再触发完整档案保存。重启、切角色时恢复最新状态，导出和复制配置包含当前显隐状态。

升级说明：从 2.5.0 更新无需删除配置，也无需重新读取游戏配置。现有自定义指令、接管布局、宏备份、快捷键和扩展栏继续使用。已在旧版通过重新读取覆盖掉的内容不会自动找回，需另查旧备份。本版沿用原正式仓库和库链，使用与已交付本地 2.5.1 相同的 DLL。

使用方法：

1. 加载新版：在 Omni 刷新原库链并更新至 2.5.1。使用本地版的用户切换在线版前，先停用旧本地条目，避免同时加载同名模块。
2. 保存修改：在「备份与导入」选定配置，正常编辑后会自动保存；需要立即落盘时点「保存」。此按钮不重新读取游戏内容，也不更新游戏设置模板。
3. 应用旧模板：打开「跨角色游戏设置模板」，点击「应用到当前角色…」，预览确认后应用。无需为了依赖更新重新建档。
4. 更新其他游戏设置：确实修改了游戏的界面或操作设置后，可在「读取／更新模板」读取并确认保存模板。此操作不改动接管栏的自定义指令。
5. 切换显隐：使用原有命令或设置页显示开关。状态先单独保存成功再生效；已成功保存的显隐状态不依赖正常退出回调。
6. 重建接管档案：确有需要时展开「重新读取游戏配置」，读取预览，确认覆盖范围并勾选后保存。日常保存不使用此入口。

注意事项：显隐小记录仍需磁盘写入，不能承诺任何环境下绝对无卡顿；技能、指令、布局、宏备份等内容修改仍需保存完整配置。切图、待机或其他插件引起的卡顿需另行观察，不能据此认定全部解决。

存储位置仍在 Omni 配置目录：主配置 HotbarWorkshopProfiles.json；显隐状态 HotbarWorkshopVisibility；游戏设置应用前备份 HotbarWorkshopGameSettingsBackups。状态按配置身份和栏位身份恢复，不将旧记录套到重新创建的栏位。
