# OmniToolbox.yuzi

Yuzi 的 OmniToolbox（树树妙妙屋）在线模块仓库。

当前正式清单使用 DLL 交付。隐藏目标圈、快捷出售和极限技调整来自 `OmniToolbox-Yuzi-Local-Omni1.1.8.5-20261028` 修复包，最低宿主为 Omni **1.1.8.5**；成就追踪 **1.1.0** 使用本仓库源码构建，最低宿主为 Omni **1.1.8.6**。

| 模块 | 发布文件 | 版本 |
| --- | --- | --- |
| 隐藏目标圈 | `Modules/HideTargetCircle.dll` | 0.1.6 |
| 快捷出售 | `Modules/SellOnClick.dll` | 0.2.9 |
| 极限技调整 | `Modules/LimitBreakAdjustments.dll` | 0.1.6 |
| 按键连点 | `Modules/KeyRepeater.dll` | 0.2.7 |

## 模块列表

- **快捷出售**（QuickSell）— 按住选中的 Alt、Ctrl、Shift 修饰键并右键单击物品，在 NPC 商店或雇员出售界面执行游戏原生出售动作；修饰键和自动确认设置会保存到本机配置。
- **极限技调整**（LimitBreakAdjustments）— 调整极限技条旋转、条间距、文本位置与显示，并提供三条极限技预览。
- **成就追踪**（AchievementTracker）— 直接读取游戏原生目标列表和成就数据；在成就界面右键选择「加入目标列表」即可自动同步至本模块。有计数器的成就显示实时进度，无计数器的成就显示达成条件，支持按角色保存、地区过滤和手动搜索添加。地区预设优先使用游戏数据中的明确关联，再使用离线整理的补充映射；启用后可使用 `/omni 成就追踪悬浮窗` 切换游戏内窗口。
- **隐藏目标圈**（HideTargetCircle）— 默认隐藏选中目标的目标圈，可选拔出武器或战斗状态时显示，并设置战斗结束后的延迟隐藏时间。
- **按键连点**（KeyRepeater）— 自动读取原生主、副技能栏绑定，支持“·”、M3/M4/M5 及组合键；工坊接管时自动改用预留 IPC，连点其独立键盘快捷键。工坊内置连点与外部连点自动互斥。工坊 2.3.0 的外部接口不接受鼠标键，接管时需用工坊内置连点处理鼠标绑定。

- **热键栏工坊**（NativeDragHotbar，2.5.1）— 接替游戏原生热键栏，支持自由布局、独立快捷键、职业切换与扩展栏，提供连点、备份和还原。支持独立保存位置、本机多套配置、实时用户宏、跨角色游戏设置模板及统一备份；修正旧模板兼容检查，区分读取与保存，显隐状态独立保存。也可不启用接管，只使用扩展栏。最低 Omni 1.1.8.9。

## 在 Omni 中添加

在「插件设置 → 在线模块」中填写清单地址：

```
https://raw.githubusercontent.com/yuanzil1243-oss/OmniToolbox.yuzi/main/TreeHouseModules.json
```

首次安装后模块默认关闭，请在「树树妙妙屋 → 在线」中手动启用。

## 仓库内容

- `Modules/`：模块源码与正式发布的 DLL。
- `TreeHouseModules.json`：在线模块清单，包含版本、下载路径及 SHA256。
- `build/`、`tests/`：构建工程、打包脚本与回归测试。

公告、开发前确认、历史发布记录及摘要副本仅供本地使用，不纳入在线模块仓库；历史资料可从 Git 历史查阅。打包脚本需要的本次版本说明在本地 `docs/` 中准备。
